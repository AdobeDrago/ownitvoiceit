Rules from the repo's AGENTS.md

  • Markup comes from the backend: fetch /path.plain.html before writing a block.
  • buildAutoBlocks rewrites content before a block runs; authors omit and add cells, so decorate defensively.
  • Scope CSS to .blockname; -wrapper and -container are section classes.
  • A PR without a {branch}--ownitvoiceit--AdobeDrago.aem.page/{path} link is rejected.
  • Merging main ships code; content is previewed and published separately in DA.
  • All committed files are served — use .hlxignore for anything that should not be.

Authoring workflow in DA.live

  1. Open da.live/#/adobedrago/ownitvoiceit and edit the document.
  2. Preview from DA (or use the Sidekick) and check https://main--ownitvoiceit--adobedrago.aem.page/.
  3. For a code change, branch from main, push, and open the PR with the <branch>--ownitvoiceit--adobedrago.aem.page link.
  4. Publish content to .aem.live after QA.
